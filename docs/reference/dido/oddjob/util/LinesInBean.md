# dido:lines-in

Creates an In for Lines of Text. The `dido.data.DidoData` is created
with a single field with the given field name or the name 'Line'.

### Property Summary

| Property | Description |
| -------- | ----------- |
| [fieldName](#propertyfieldname) | The name of the field for the data. |
